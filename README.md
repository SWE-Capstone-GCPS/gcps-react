# React + Vite

GCPS Bus Project
Overview
The GCPS Bus Project is a system designed to manage and track school buses for the Gwinnett County Public Schools (GCPS). This project aims to improve the efficiency of bus routes, enhance student safety, and provide real-time information to parents and school administrators.

Features
Real-time bus tracking
Route optimization
Student ridership management
Parent notification system
Driver management
Maintenance scheduling
Installation
To set up the GCPS Bus Project locally, follow these steps:

Clone the repository:
git clone https://github.com/your-username/gcps-bus-project.git

Navigate to the project directory:
cd gcps-bus-project

Install dependencies:
npm install

### JavaScript Libraries

- react==18.3.1
- react-dom==18.3.1
- mapbox-gl==2.15.0

## Installation

1. Install Python dependencies:

   ```
   pip install confluent-kafka pyodbc websockets
   ```

2. Install JavaScript dependencies:
   ```
   npm install react react-dom mapbox-gl
   ```

Start the development server:
npm run dev

Technologies Used
Frontend: React.js
Backend: Python, Node.js with Express
Database: MySQL
Real-time updates: Socket.io
Maps integration: Mapbox GL
